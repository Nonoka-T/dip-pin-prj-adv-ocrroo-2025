# Persona: Sean

## Background
Sean is 34 and lives in Perth, WA.
He works as a phone operator and wants to change careers to become a software developer
so he is learning Python in his own time. 
He has had low vision since he was a child. He can read large text close up,
but small text on a screen is too hard to read. 
He uses a Windows laptop with the NVDA screen reader and large text settings
and he writes code in VS Code. 
He is confident with NVDA and uses the keyboard for almost everything, but he has never used an OCR tool before.
From his job, he's fast at typing while listening to callers so he is used to listening to NVDA and
typing at the same time. He is patient, a little shy and kind, and he enjoys music and meditation.

## Goals
- Learn Python by following coding videos
- Get the exact code shown in a video not only what the speaker says
- Study on his own at his own speed without asking someone to read the screen

## Needs
- Every action can be done with the keyboard
- Button have clear names and result and errors are read out by NVDA
- Code can be shown in large text and the size is remembered
- Clear messages when something goes wrong. For example, when the server is not running

## Pain points:
- Speakers in coding videos often don't read the code out
- Small code on the screen is hard to read even he zooms in the screen
- Many tools have buttons with no label so NVDA only says "button"
- He studies after work so he has limited time and can't wait for help
